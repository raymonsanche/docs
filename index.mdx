## Overview

Simple API is a RESTful API for managing event-driven notification delivery. You can register clients, configure webhooks, define events, and control how notifications are routed and delivered. The API also includes general-purpose resources for products, categories, services, and accounts.

## Key features

- **Notification pipeline** - Configure events, webhooks, delivery settings, mutators, and rulesets to build a flexible notification workflow
- **Client feature flags** - Toggle per-client capabilities like payload signing and event reprocessing
- **Event reprocessing** - List and retry rejected notifications by status, time interval, or trace ID
- **Issuer API** - Self-service endpoints for issuers to manage webhooks, test notifications, and reprocess events
- **Standard REST** - JSON request and response bodies with conventional HTTP methods
