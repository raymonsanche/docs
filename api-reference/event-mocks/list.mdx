---
title: "List event mocks"
api: "GET /event-mocks"
description: "Retrieve all event mock definitions"
---

Retrieve all event mock definitions, optionally filtered by ID or event name. Event mocks provide sample payloads that you can use to test notification delivery without generating real events.

## Endpoint

```
GET /event-mocks
```

## Query parameters

<ParamField query="id" type="string">
  Filter by event mock ID (UUID)
</ParamField>

<ParamField query="event_name" type="string">
  Filter by event name
</ParamField>

## Request example

```bash
curl "/event-mocks?event_name=payment.created"
```

## Response

Returns an array of event mock objects.

<ResponseField name="id" type="string">
  Unique identifier (UUID)
</ResponseField>

<ResponseField name="event_name" type="string">
  Name of the associated event
</ResponseField>

<ResponseField name="payload" type="object">
  Sample event payload used for testing
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update timestamp
</ResponseField>

### Success response (200)

```json
[
  {
    "id": "a7b8c9d0-e1f2-3456-7890-abcdef123456",
    "event_name": "payment.created",
    "payload": {
      "transaction_id": "txn_123456",
      "amount": 1500,
      "currency": "BRL",
      "status": "completed"
    },
    "created_at": "2026-01-15T10:30:00Z",
    "updated_at": "2026-01-15T10:30:00Z"
  }
]
```

## Use cases

- List available mock payloads before testing webhook delivery
- Verify which events have mock definitions configured
