---
title: "Get event mock"
api: "GET /event-mocks/{id}"
description: "Retrieve a single event mock by ID"
---

Retrieve a single event mock definition by its unique identifier.

## Endpoint

```
GET /event-mocks/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The UUID of the event mock to retrieve
</ParamField>

## Request example

```bash
curl "/event-mocks/a7b8c9d0-e1f2-3456-7890-abcdef123456"
```

## Response

### Success response (200)

```json
{
  "id": "a7b8c9d0-e1f2-3456-7890-abcdef123456",
  "event_name": "payment.created",
  "payload": {
    "transaction_id": "txn_123456",
    "amount": 1500,
    "currency": "BRL",
    "status": "completed"
  },
  "created_at": "2026-01-15T10:30:00Z",
  "updated_at": "2026-01-15T10:30:00Z"
}
```

### Error response (404)

```json
{
  "error": "not found"
}
```
