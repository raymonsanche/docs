---

Retrieve a specific category by ID.

## Endpoint

```
GET /categories/:id
```

## Path parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the category
</ParamField>

## Request example

```bash
curl http://localhost:8000/categories/1
```

## Response

<ResponseField name="id" type="integer">
  Unique identifier for the category
</ResponseField>

<ResponseField name="name" type="string">
  Category name
</ResponseField>

<ResponseField name="description" type="string">
  Category description
</ResponseField>

### Success response (200)

```json
{
  "id": 1,
  "name": "Electronics",
  "description": "Electronic devices and accessories"
}
```

### Error response (404)

If the category doesn't exist:

```json
{
  "error": "not found"
}
```

## Use cases

- Retrieve category details for display
- Verify a category exists before assigning products
- Get category information for reports

<Tip>
Check the HTTP status code. A 404 response means the category ID doesn't exist.
</Tip>
