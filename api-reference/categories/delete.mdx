---
title: "Delete category"
api: "DELETE /categories/:id"
description: "Delete a category"
---

Delete a category from the system.

## Endpoint

```
DELETE /categories/:id
```

## Path parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the category to delete
</ParamField>

## Request example

```bash
curl -X DELETE http://localhost:8000/categories/1
```

## Response

<ResponseField name="deleted" type="boolean">
  Confirmation that the deletion was successful
</ResponseField>

### Success response (200)

```json
{
  "deleted": true
}
```

### Error response (404)

If the category doesn't exist:

```json
{
  "error": "not found"
}
```

## Use cases

- Remove unused categories
- Clean up test category data
- Delete duplicate category entries

<Warning>
Deleting a category is permanent and cannot be undone.
</Warning>
