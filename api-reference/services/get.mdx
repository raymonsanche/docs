api: "GET /services/:id"

---

Retrieve a specific service by ID.

## Endpoint

```
GET /services/:id
```

## Path parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the service
</ParamField>

## Request example

```bash
curl http://localhost:8000/services/1
```

## Response

<ResponseField name="id" type="integer">
  Unique identifier for the service
</ResponseField>

<ResponseField name="name" type="string">
  Service name
</ResponseField>

<ResponseField name="price" type="number">
  Service price
</ResponseField>

<ResponseField name="description" type="string">
  Service description
</ResponseField>

### Success response (200)

```json
{
  "id": 1,
  "name": "Technical Support",
  "price": 99.99,
  "description": "24/7 technical support"
}
```

### Error response (404)

If the service doesn't exist:

```json
{
  "error": "not found"
}
```

## Use cases

- Retrieve service details for display
- Check service pricing
- Get service information before updating

<Tip>
Check the HTTP status code. A 404 response means the service ID doesn't exist.
</Tip>
