---
title: "Delete service"
api: "DELETE /services/:id"
description: "Delete a service"
---

Delete a service from the system.

## Endpoint

```
DELETE /services/:id
```

## Path parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the service to delete
</ParamField>

## Request example

```bash
curl -X DELETE http://localhost:8000/services/1
```

## Response

<ResponseField name="deleted" type="boolean">
  Confirmation that the deletion was successful
</ResponseField>

### Success response (200)

```json
{
  "deleted": true
}
```

### Error response (404)

If the service doesn't exist:

```json
{
  "error": "not found"
}
```

## Use cases

- Remove discontinued services
- Clean up test service data
- Delete duplicate service entries

<Warning>
Deleting a service is permanent and cannot be undone.
</Warning>
