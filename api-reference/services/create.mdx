---
title: "Create service"
api: "POST /services"
description: "Create a new service"
---

Create a new service offering.

## Endpoint

```
POST /services
```

## Request body

<ParamField body="name" type="string" required>
  Service name
</ParamField>

<ParamField body="price" type="number">
  Service price
</ParamField>

<ParamField body="description" type="string">
  Service description
</ParamField>

## Request example

```bash
curl -X POST http://localhost:8000/services \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Technical Support",
    "price": 99.99,
    "description": "24/7 technical support"
  }'
```

## Response

<ResponseField name="id" type="integer">
  Unique identifier for the newly created service (auto-generated)
</ResponseField>

<ResponseField name="name" type="string">
  Service name
</ResponseField>

<ResponseField name="price" type="number">
  Service price
</ResponseField>

<ResponseField name="description" type="string">
  Service description
</ResponseField>

### Success response (201)

```json
{
  "id": 1,
  "name": "Technical Support",
  "price": 99.99,
  "description": "24/7 technical support"
}
```

## Use cases

- Define a new service offering for clients
- Add support or maintenance plans to your catalog
- Register professional services with pricing

<Note>
The ID field is automatically assigned by the server. Do not include it in your request.
</Note>
