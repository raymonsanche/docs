---
title: "Create client"
api: "POST /clients"
description: "Create a new client"
---

Create a new client in the system. At least one of `client_id` or `legacy_id` is required.

## Endpoint

```
POST /clients
```

## Request body

<ParamField body="name" type="string">
  Client name
</ParamField>

<ParamField body="client_id" type="string">
  External client identifier. Either `client_id` or `legacy_id` (or both) must be provided.
</ParamField>

<ParamField body="legacy_id" type="integer">
  Legacy numeric client identifier. Either `client_id` or `legacy_id` (or both) must be provided.
</ParamField>

<ParamField body="secret_name" type="string">
  Secret name reference for the client
</ParamField>

<ParamField body="aes_key" type="string">
  AES encryption key for the client (base64-encoded)
</ParamField>

## Request example

```bash
curl -X POST /clients \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Client",
    "client_id": "client-abc-123",
    "legacy_id": 12345,
    "secret_name": "my-client-secret"
  }'
```

## Response

<ResponseField name="id" type="string">
  Unique identifier for the client (UUID, auto-generated)
</ResponseField>

<ResponseField name="name" type="string">
  Client name
</ResponseField>

<ResponseField name="client_id" type="string">
  External client identifier
</ResponseField>

<ResponseField name="legacy_id" type="integer">
  Legacy numeric client identifier
</ResponseField>

<ResponseField name="has_aes_key" type="boolean">
  Whether the client has an AES encryption key configured
</ResponseField>

<ResponseField name="secret_name" type="string">
  Secret name reference for the client
</ResponseField>

<ResponseField name="created_at" type="string">
  Timestamp when the client was created
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp when the client was last updated
</ResponseField>

### Success response (201)

```json
{
  "id": "c9d8e7f6-5432-1098-abcd-fedcba987654",
  "name": "My Client",
  "client_id": "client-abc-123",
  "legacy_id": 12345,
  "has_aes_key": false,
  "secret_name": "my-client-secret",
  "created_at": "2026-01-15T10:30:00Z",
  "updated_at": "2026-01-15T10:30:00Z"
}
```

### Error response (400)

If neither `client_id` nor `legacy_id` is provided:

```json
{
  "error": "bad request"
}
```

## Rules

- At least one of `client_id` or `legacy_id` is required
- The `client_id` must be unique across all clients
- The `legacy_id` must be a positive integer and unique across all clients
- The `id` field is a UUID automatically assigned by the server

## Use cases

- Register a new client for webhook event delivery
- Onboard a client with a specific external identifier or legacy ID
- Set up a client with an encryption key for secure payload delivery
