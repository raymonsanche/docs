---
title: "Delete client"
api: "DELETE /clients/:id"
description: "Delete a client"
---

Delete a specific client from the system.

## Endpoint

```
DELETE /clients/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  The UUID of the client to delete
</ParamField>

## Query parameters

<ParamField query="client_id" type="string">
  External client identifier (optional, for additional validation)
</ParamField>

<ParamField query="legacy_id" type="integer">
  Legacy numeric client identifier (optional, for additional validation)
</ParamField>

## Request example

```bash
curl -X DELETE /clients/c9d8e7f6-5432-1098-abcd-fedcba987654
```

## Response

### Success response (204)

No content is returned.

### Error response (404)

If the client doesn't exist:

```json
{
  "error": "not found"
}
```

## Rules

- The `id` must be a valid UUID
- Permanently removes the client and its associated data
- If the client has foreign key dependencies (such as feature flags or webhooks), the deletion fails with an error

<Warning>
Deleting a client is permanent and cannot be undone. All associated feature flags and configurations are also removed.
</Warning>

## Use cases

- Remove inactive or decommissioned clients
- Clean up duplicate client records
- Delete test or temporary client data
