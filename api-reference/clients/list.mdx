---
title: "List clients"
api: "GET /clients"
description: "Retrieve all clients"
---

Retrieve all clients from the system.

## Endpoint

```
GET /clients
```

## Query parameters

Use query parameters to filter results. If no parameters are provided, all clients are returned.

<ParamField query="id" type="string">
  Filter by client UUID
</ParamField>

<ParamField query="client_id" type="string">
  Filter by external client identifier
</ParamField>

<ParamField query="legacy_id" type="integer">
  Filter by legacy numeric client identifier
</ParamField>

## Request examples

List all clients:

```bash
curl http://localhost:8000/clients
```

Filter by external client identifier:

```bash
curl "http://localhost:8000/clients?client_id=acme-123"
```

Filter by legacy ID:

```bash
curl "http://localhost:8000/clients?legacy_id=12345"
```

## Response

Returns an array of all clients in the system.

<ResponseField name="id" type="string">
  Unique identifier for the client (UUID)
</ResponseField>

<ResponseField name="name" type="string">
  Client name
</ResponseField>

<ResponseField name="client_id" type="string">
  External client identifier
</ResponseField>

<ResponseField name="legacy_id" type="integer">
  Legacy numeric client identifier
</ResponseField>

<ResponseField name="has_aes_key" type="boolean">
  Whether the client has an AES encryption key configured
</ResponseField>

<ResponseField name="secret_name" type="string">
  Secret name reference for the client
</ResponseField>

<ResponseField name="feature_flags" type="object">
  Feature flag configuration for the client

  <Expandable title="Feature flags object">
    <ResponseField name="payload_signature_enabled" type="boolean">
      Whether payload signature verification is enabled
    </ResponseField>

    <ResponseField name="reprocess_by_status_enabled" type="boolean">
      Whether event reprocessing by notification status is enabled
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created_at" type="string">
  Timestamp when the client was created
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp when the client was last updated
</ResponseField>

### Success response (200)

```json
[
  {
    "id": "c9d8e7f6-5432-1098-abcd-fedcba987654",
    "name": "My Client",
    "client_id": "client-abc-123",
    "legacy_id": 12345,
    "has_aes_key": true,
    "secret_name": "my-client-secret",
    "feature_flags": {
      "payload_signature_enabled": false,
      "reprocess_by_status_enabled": true
    },
    "created_at": "2026-01-15T10:30:00Z",
    "updated_at": "2026-03-20T14:00:00Z"
  }
]
```

### Empty list response

If no clients exist, returns an empty array:

```json
[]
```

## Use cases

- Display a list of all clients in your application
- Check which feature flags are enabled per client
- Audit client configurations and encryption key status
