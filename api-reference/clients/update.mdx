---
title: "Update client"
api: "PUT /clients/:id"
description: "Update an existing client"
---

Replace a client's configuration. This endpoint updates the full client record including feature flags and encryption key settings.

## Endpoint

```
PUT /clients/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  The UUID of the client to update
</ParamField>

## Request body

<ParamField body="name" type="string">
  Updated client name
</ParamField>

<ParamField body="client_id" type="string">
  Updated external client identifier
</ParamField>

<ParamField body="legacy_id" type="integer">
  Updated legacy numeric client identifier
</ParamField>

<ParamField body="secret_name" type="string">
  Updated secret name reference
</ParamField>

<ParamField body="aes_key" type="string">
  Updated AES encryption key (base64-encoded). If omitted, the existing key is preserved.
</ParamField>

<ParamField body="payload_signature_enabled" type="boolean">
  Whether payload signature verification is enabled for this client
</ParamField>

<ParamField body="reprocess_by_status_enabled" type="boolean">
  Whether event reprocessing by notification status is enabled for this client
</ParamField>

## Request example

```bash
curl -X PUT /clients/c9d8e7f6-5432-1098-abcd-fedcba987654 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Client",
    "client_id": "client-abc-123",
    "legacy_id": 12345,
    "secret_name": "updated-secret",
    "payload_signature_enabled": true,
    "reprocess_by_status_enabled": false
  }'
```

## Response

### Success response (200)

```json
{
  "message": "client has been updated."
}
```

### Error response (404)

If the client doesn't exist:

```json
{
  "error": "not found"
}
```

## Rules

- The `id` must be a valid UUID
- If `aes_key` is omitted, the existing encryption key is preserved
- Feature flag fields (`payload_signature_enabled`, `reprocess_by_status_enabled`) are updated alongside the client record

## Use cases

- Update client identifiers or name
- Enable or disable feature flags as part of a full client update
- Rotate a client's encryption key

<Tip>
For lightweight updates to just `name` or `secret_name`, use [patch client](/api-reference/clients/patch) instead.
</Tip>
