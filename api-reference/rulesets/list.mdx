---
title: "List rulesets"
api: "GET /rulesets"
description: "Retrieve all ruleset configurations"
---

Retrieve all ruleset configurations, optionally filtered by source, event type, or event name. Rulesets define routing and filtering rules that determine how incoming events are classified and matched to event definitions.

## Endpoint

```
GET /rulesets
```

## Query parameters

<ParamField query="id" type="string">
  Filter by ruleset ID (UUID)
</ParamField>

<ParamField query="source" type="string">
  Filter by event source
</ParamField>

<ParamField query="event_type" type="string">
  Filter by event type
</ParamField>

<ParamField query="event_name" type="string">
  Filter by target event name
</ParamField>

## Request example

```bash
curl "/rulesets?source=payment-gateway&event_type=transaction"
```

## Response

Returns an array of ruleset objects.

<ResponseField name="id" type="string">
  Unique identifier (UUID)
</ResponseField>

<ResponseField name="source" type="string">
  Event source identifier
</ResponseField>

<ResponseField name="event_type" type="string">
  Event type
</ResponseField>

<ResponseField name="event_type_alias" type="string">
  Optional alias for the event type
</ResponseField>

<ResponseField name="event_name" type="string">
  Target event name this ruleset maps to
</ResponseField>

<ResponseField name="rules" type="array">
  Array of rule objects that define matching conditions

  <Expandable title="Rule object">
    <ResponseField name="json_path" type="string">
      JSONPath expression identifying the field to evaluate
    </ResponseField>

    <ResponseField name="match_value" type="any">
      Value to match against
    </ResponseField>

    <ResponseField name="exclude" type="boolean">
      When `true`, excludes events that match instead of including them
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update timestamp
</ResponseField>

### Success response (200)

```json
[
  {
    "id": "c3d4e5f6-a7b8-9012-cdef-123456789012",
    "source": "payment-gateway",
    "event_type": "transaction",
    "event_type_alias": "payment_transaction",
    "event_name": "payment.created",
    "rules": [
      {
        "json_path": "$.payload.status",
        "match_value": "completed",
        "exclude": false
      }
    ],
    "created_at": "2026-01-15T10:30:00Z",
    "updated_at": "2026-01-15T10:30:00Z"
  }
]
```

## Use cases

- List all routing rules for a specific event source
- Audit how incoming events are mapped to event definitions
- Review filtering conditions before modifying event routing
