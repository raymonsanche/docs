---
title: "Get ruleset"
api: "GET /rulesets/{id}"
description: "Retrieve a single ruleset by ID"
---

Retrieve a single ruleset configuration by its unique identifier.

## Endpoint

```
GET /rulesets/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The UUID of the ruleset to retrieve
</ParamField>

## Request example

```bash
curl "/rulesets/c3d4e5f6-a7b8-9012-cdef-123456789012"
```
