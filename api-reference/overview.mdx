The Simple API provides resources for managing event-driven notification delivery. You can configure events, webhooks, delivery settings, mutators, rulesets, and more to build a flexible notification pipeline.

## Available resources

### Events

Define event types that your system can produce and deliver. Events are the foundation of the notification pipeline — you must register an event before configuring webhooks or delivery settings for it.

- [List events](/api-reference/events/list)
- [Create event](/api-reference/events/create)
- [Get event](/api-reference/events/get)
- [Update event](/api-reference/events/update)
- [Delete event](/api-reference/events/delete)

## Base URL

```
http://localhost:8000
```

## Authentication

The Simple API does not require authentication. All endpoints are publicly accessible.

## Response format

All responses use JSON format. Successful responses contain the requested data, while errors are formatted as:

```json
{
  "error": "not found"
}
```

## Status codes

| Code | Description |
| --- | --- |
| 200 | OK - Request succeeded |
| 201 | Created - Resource was created successfully |
| 204 | No Content - Resource was deleted successfully |
| 400 | Bad Request - Missing or invalid parameters |
| 404 | Not Found - Resource or endpoint doesn't exist |
| 409 | Conflict - Resource already exists or is still referenced |

## Rate limiting

No rate limiting is applied to the Simple API.

## Pagination

The Simple API does not support pagination. List endpoints return all available resources.

<Tip>
All endpoints follow the same pattern. Once you understand one resource type, you can apply the same operations to all others.
</Tip>
