---
title: "List webhooks"
api: "GET /webhooks"
description: "Retrieve all webhook configurations"
---

Retrieve all webhook configurations, optionally filtered by event name, client, or URL.

## Endpoint

```
GET /webhooks
```

## Query parameters

<ParamField query="id" type="string">
  Filter by webhook ID (UUID)
</ParamField>

<ParamField query="event_name" type="string">
  Filter by event name
</ParamField>

<ParamField query="client_id" type="string">
  Filter by client ID
</ParamField>

<ParamField query="legacy_id" type="integer">
  Filter by legacy client ID
</ParamField>

<ParamField query="url" type="string">
  Filter by webhook URL
</ParamField>

## Request example

```bash
curl "/webhooks?event_name=payment.created&client_id=abc123"
```

## Response

Returns an array of webhook objects.

<ResponseField name="id" type="string">
  Unique identifier (UUID) for the webhook
</ResponseField>

<ResponseField name="event_name" type="string">
  Name of the event this webhook subscribes to
</ResponseField>

<ResponseField name="url" type="string">
  Destination URL where notifications are sent
</ResponseField>

<ResponseField name="client_id" type="string">
  Client identifier
</ResponseField>

<ResponseField name="legacy_id" type="integer">
  Legacy client identifier
</ResponseField>

<ResponseField name="headers" type="object">
  Custom HTTP headers sent with each notification (values are masked for security)
</ResponseField>

<ResponseField name="auth_type" type="string">
  Authentication type used when calling the webhook URL
</ResponseField>

<ResponseField name="filter" type="object">
  Optional filter applied to incoming events

  <Expandable title="Filter object">
    <ResponseField name="field" type="string">
      JSONPath expression identifying the field to filter on
    </ResponseField>

    <ResponseField name="type" type="string">
      Filter comparison type (for example, `equals`)
    </ResponseField>

    <ResponseField name="value" type="string | number | boolean">
      Value to match against. The type matches the corresponding mutator template field type.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created_at" type="string">
  Timestamp when the webhook was created
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp when the webhook was last updated
</ResponseField>

[
  {

    "event_name": "payment.created",

    "client_id": "abc123",
    "legacy_id": 12345,
    "headers": {
      "Authorization": "(length: 42)"
    },
    "auth_type": "bearer",
    "filter": {
      "field": "$.payload.status",
      "type": "equals",

<Note>
Header values are masked in list responses for security. Only the length of each value is shown.
</Note>

## Use cases

- List all webhooks subscribed to a specific event
- Find all webhook configurations for a client
- Audit webhook endpoints before reprocessing events
