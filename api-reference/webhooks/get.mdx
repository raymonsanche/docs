---
title: "Get webhook"
api: "GET /webhooks/{id}"
description: "Retrieve a single webhook by ID"
---

Retrieve a single webhook configuration by its unique identifier.

## Endpoint

```
GET /webhooks/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The UUID of the webhook to retrieve
</ParamField>

## Request example

```bash
curl "/webhooks/d4e5f6a7-b8c9-0123-4567-890abcdef012"
```

## Response

<ResponseField name="id" type="string">
  Unique identifier (UUID) for the webhook
</ResponseField>

<ResponseField name="event_name" type="string">
  Name of the subscribed event
</ResponseField>

<ResponseField name="url" type="string">
  Destination URL
</ResponseField>

<ResponseField name="client_id" type="string">
  Client identifier
</ResponseField>

<ResponseField name="legacy_id" type="integer">
  Legacy client identifier
</ResponseField>

<ResponseField name="headers" type="object">
  Custom HTTP headers (values masked)
</ResponseField>

<ResponseField name="auth_type" type="string">
  Authentication type
</ResponseField>

<ResponseField name="filter" type="object">
  Event filter configuration (or `null` if no filter)

  <Expandable title="Filter object">
    <ResponseField name="field" type="string">
      JSONPath expression identifying the field to filter on (for example, `$.payload.status`)
    </ResponseField>

    <ResponseField name="type" type="string">
      Filter comparison type (for example, `equals`)
    </ResponseField>

    <ResponseField name="value" type="string | number | boolean">
      Value to match against. The type matches the corresponding mutator template field type.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update timestamp
</ResponseField>

```json
{
  "id": "d4e5f6a7-b8c9-0123-4567-890abcdef012",
  "event_name": "payment.created",
  "url": "https://example.com/webhook",
  "client_id": "abc123",
  "legacy_id": 12345,
  "headers": {
    "Authorization": "(length: 42)"
  },
  "auth_type": "bearer",
  "filter": {
    "field": "$.payload.status",
    "type": "equals",
    "value": "approved"
  },
  "created_at": "2026-01-15T10:30:00Z",
  "updated_at": "2026-01-15T10:30:00Z"
}
```

### Error response (404)

```json
{
  "error": "not found"
}
```
