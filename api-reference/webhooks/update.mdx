---
title: "Update webhook"
api: "PUT /webhooks/{id}"
description: "Update an existing webhook"
---

Update an existing webhook configuration. You can change the URL, event subscription, headers, authentication, and filter settings.

## Endpoint

```
PUT /webhooks/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The UUID of the webhook to update
</ParamField>

## Request body

<ParamField body="url" type="string" required>
  Updated destination URL
</ParamField>

<ParamField body="event_name" type="string" required>
  Updated event name
</ParamField>

<ParamField body="client_id" type="string">
  Client identifier
</ParamField>

<ParamField body="legacy_id" type="integer">
  Legacy client identifier
</ParamField>

<ParamField body="headers" type="object">
  Updated custom HTTP headers
</ParamField>

<ParamField body="auth_type" type="string">
  Updated authentication type
</ParamField>

<ParamField body="filter" type="object">
  Updated filter configuration (set to `null` to remove the filter)
</ParamField>

## Request example

```bash
curl -X PUT /webhooks/d4e5f6a7-b8c9-0123-4567-890abcdef012 \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/webhook-v2",
    "event_name": "payment.created",
    "client_id": "abc123",
    "legacy_id": 12345,
    "headers": {
      "Authorization": "Bearer new-token"
    },
    "auth_type": "bearer"
  }'
```

## Response

### Success response (200)

```json
{
  "message": "webhook has been updated."
}
```

### Error response (404)

```json
{
  "error": "not found"
}
```
