---
title: "List webhooks"
api: "GET /external/webhooks"
description: "Retrieve your webhook configurations"
---

Retrieve all webhook configurations for your issuer account, optionally filtered by ID, event name, or URL.

## Endpoint

```
GET /external/webhooks
```

## Query parameters

<ParamField query="id" type="string">
  Filter by webhook ID (UUID)
</ParamField>

<ParamField query="event_name" type="string">
  Filter by event name
</ParamField>

<ParamField query="url" type="string">
  Filter by webhook URL
</ParamField>

## Request example

```bash
curl "/external/webhooks?event_name=payment.created" \
  -H "Authorization: Bearer <your-token>"
```

## Response

Returns an array of webhook objects scoped to your issuer account.

<ResponseField name="id" type="string">
  Unique identifier (UUID) for the webhook
</ResponseField>

<ResponseField name="event_name" type="string">
  Name of the event this webhook subscribes to
</ResponseField>

<ResponseField name="url" type="string">
  Destination URL where notifications are sent
</ResponseField>

<ResponseField name="headers" type="object">
  Custom HTTP headers included with each notification request
</ResponseField>

<ResponseField name="auth_type" type="string">
  Authentication type for the webhook endpoint
</ResponseField>

<ResponseField name="filter" type="object">
  Optional event filter configuration (or `null` if no filter)

  <Expandable title="Filter object">
    <ResponseField name="field" type="string">
      JSONPath expression identifying the field to filter on (for example, `$.payload.status`)
    </ResponseField>

    <ResponseField name="type" type="string">
      Filter comparison type (for example, `equals`)
    </ResponseField>

    <ResponseField name="value" type="string">
      Value to match against
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created_at" type="string">
  Timestamp when the webhook was created
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp when the webhook was last updated
</ResponseField>

### Success response (200)

```json
[
  {
    "id": "d4e5f6a7-b8c9-0123-4567-890abcdef012",
    "event_name": "payment.created",
    "url": "https://example.com/webhook",
    "headers": {
      "Authorization": "Bearer my-secret-token"
    },
    "auth_type": "bearer",
    "filter": null,
    "created_at": "2026-01-15T10:30:00Z",
    "updated_at": "2026-01-15T10:30:00Z"
  }
]
```

### Empty response (200)

If you have no webhooks configured:

```json
[]
```

<Note>
Header values are returned unmasked in issuer API responses, so you can verify your webhook configuration. In contrast, the admin [webhooks API](/api-reference/webhooks/list) masks header values for security.
</Note>
