---
title: "Get webhook"
api: "GET /external/webhooks/{id}"
description: "Retrieve a specific webhook by ID"
---

Retrieve the configuration for a specific webhook by its ID. The webhook must belong to your issuer account.

## Endpoint

```
GET /external/webhooks/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  UUID of the webhook to retrieve
</ParamField>

## Request example

```bash
curl /external/webhooks/d4e5f6a7-b8c9-0123-4567-890abcdef012 \
  -H "Authorization: Bearer <your-token>"
```

## Response

<ResponseField name="id" type="string">
  Unique identifier (UUID) for the webhook
</ResponseField>

<ResponseField name="event_name" type="string">
  Name of the event this webhook subscribes to
</ResponseField>

<ResponseField name="url" type="string">
  Destination URL where notifications are sent
</ResponseField>

<ResponseField name="client_id" type="string">
  Your client identifier
</ResponseField>

<ResponseField name="legacy_id" type="integer">
  Your legacy client identifier
</ResponseField>

<ResponseField name="headers" type="object">
  Custom HTTP headers included with each notification request
</ResponseField>

<ResponseField name="auth_type" type="string">
  Authentication type
</ResponseField>

<ResponseField name="filter" type="object">
  Optional event filter configuration
</ResponseField>

<ResponseField name="created_at" type="string">
  Timestamp when the webhook was created
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp when the webhook was last updated
</ResponseField>

### Success response (200)

```json
{
  "id": "d4e5f6a7-b8c9-0123-4567-890abcdef012",
  "event_name": "payment.created",
  "url": "https://example.com/webhook",
  "client_id": "abc123",
  "legacy_id": 12345,
  "headers": {
    "Authorization": "Bearer my-secret-token"
  },
  "auth_type": "bearer",
  "filter": null,
  "created_at": "2026-01-15T10:30:00Z",
  "updated_at": "2026-01-15T10:30:00Z"
}
```

### Error response (404)

If the webhook does not exist or does not belong to your account:

```json
{
  "error": "not found"
}
```
