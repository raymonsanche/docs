---
title: "List events"
api: "GET /events"
description: "Retrieve all event definitions"
---

Retrieve all event definitions, optionally filtered by ID or name.

## Endpoint

```
GET /events
```

## Query parameters

<ParamField query="id" type="string">
  Filter by event ID (UUID)
</ParamField>

<ParamField query="name" type="string">
  Filter by event name (exact match)
</ParamField>

## Request example

```bash
curl "/events"
```

To filter by name:

```bash
curl "/events?name=payment.created"
```

## Response

Returns an array of event objects.

<ResponseField name="id" type="string">
  Unique identifier (UUID) for the event
</ResponseField>

<ResponseField name="name" type="string">
  Event name
</ResponseField>

<ResponseField name="unique_fields" type="array">
  Array of objects specifying fields used for deduplication

  <Expandable title="Unique field object">
    <ResponseField name="field_path" type="string">
      JSONPath expression identifying the field
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created_at" type="string">
  Timestamp when the event was created
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp when the event was last updated
</ResponseField>

### Success response (200)

```json
[
  {
    "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "name": "payment.created",
    "unique_fields": [
      {
        "field_path": "$.payload.transaction_id"
      }
    ],
    "created_at": "2026-01-15T10:30:00Z",
    "updated_at": "2026-01-15T10:30:00Z"
  }
]
```

### Empty response (200)

If no events match, returns an empty array:

```json
[]
```

## Use cases

- List all registered event types in your system
- Search for a specific event by name before creating webhooks
- Audit which events are available for subscription
