---
title: "List mutators"
api: "GET /mutators"
description: "Retrieve all mutator configurations"
---

Retrieve all mutator configurations, optionally filtered by event name or type. Mutators define transformations applied to event payloads before they are delivered.

## Endpoint

```
GET /mutators
```

## Query parameters

<ParamField query="id" type="string">
  Filter by mutator ID (UUID)
</ParamField>

<ParamField query="event_name" type="string">
  Filter by event name (exact match)
</ParamField>

<ParamField query="mutator_type" type="string">
  Filter by mutator type
</ParamField>

## Request example

```bash
curl "/mutators?event_name=payment.created"
```

## Response

Returns an array of mutator objects.

<ResponseField name="id" type="string">
  Unique identifier (UUID)
</ResponseField>

<ResponseField name="event_name" type="string">
  Name of the event this mutator applies to
</ResponseField>

<ResponseField name="mutator_type" type="string">
  Type of transformation (for example, `msk`)
</ResponseField>

<ResponseField name="parameters" type="object">
  Mutator configuration including the transformation template
</ResponseField>

<ResponseField name="ordering_key" type="integer">
  Execution order priority. Mutators with lower values run first.
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp
</ResponseField>

<ResponseField name="updated_at" type="string">
  Last update timestamp
</ResponseField>

### Success response (200)

```json
[
  {
    "id": "b2c3d4e5-f6a7-8901-bcde-f12345678901",
    "event_name": "payment.created",
    "mutator_type": "msk",
    "parameters": {
      "template": {
        "card_number": "$.payload.card_number"
      },
      "fill_missing_keys": "deep"
    },
    "ordering_key": 10,
    "created_at": "2026-01-15T10:30:00Z",
    "updated_at": "2026-01-15T10:30:00Z"
  }
]
```

## Use cases

- List all transformations configured for a specific event
- Audit the order in which mutators are applied to payloads
- Review masking or enrichment rules before delivery
