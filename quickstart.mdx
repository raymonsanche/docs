Get the API running and make your first API calls in just a few minutes.

## Prerequisites

- Python 3.6 or higher
- A terminal or command prompt
- curl, Postman, or any HTTP client

## 1. Start the server

Navigate to your project directory and start the API server:

```bash
python3 main.py
```

You should see:

```
Server running on http://localhost:8000
Routes: /clients, /products, /categories, /services, /accounts
```

## 2. Create your first client

Send a POST request to create a new client:

```bash
curl -X POST http://localhost:8000/clients \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Acme Corp",
    "client_id": "acme-123",
    "legacy_id": 1001
  }'
```

Expected response:

```json
{
  "id": "c9d8e7f6-5432-1098-abcd-fedcba987654",
  "name": "Acme Corp",
  "client_id": "acme-123",
  "legacy_id": 1001,
  "has_aes_key": false,
  "secret_name": null,
  "created_at": "2026-01-15T10:30:00Z",
  "updated_at": "2026-01-15T10:30:00Z"
}
```

## 3. List all clients

Retrieve all clients:

```bash
curl http://localhost:8000/clients
```

Response:

```json
[
  {
    "id": "c9d8e7f6-5432-1098-abcd-fedcba987654",
    "name": "Acme Corp",
    "client_id": "acme-123",
    "legacy_id": 1001,
    "has_aes_key": false,
    "secret_name": null,
    "feature_flags": {
      "payload_signature_enabled": false,
      "reprocess_by_status_enabled": false
    },
    "created_at": "2026-01-15T10:30:00Z",
    "updated_at": "2026-01-15T10:30:00Z"
  }
]
```

## 4. Get a specific client

Retrieve a client by ID:

```bash
curl http://localhost:8000/clients/c9d8e7f6-5432-1098-abcd-fedcba987654
```

## 5. Update a client

Update an existing client:

```bash
curl -X PUT http://localhost:8000/clients/c9d8e7f6-5432-1098-abcd-fedcba987654 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Acme Corp Updated",
    "client_id": "acme-123",
    "legacy_id": 1001,
    "payload_signature_enabled": true
  }'
```

## 6. Delete a client

Delete a client by ID:

```bash
curl -X DELETE http://localhost:8000/clients/c9d8e7f6-5432-1098-abcd-fedcba987654
```
